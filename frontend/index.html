使用方式

先创建流程，再执行下一步。检查提示词和中间结果满意后，可连续执行剩余步骤。

每次自动生成读取对应模块已保存的 API、System Prompt 与 User Prompt，并在 User Prompt 末尾补充本步范围、素材顺序和时长。不使用模拟结果。

空间替换用视频模块，新首图用图生图模块，首尾过渡用 I2V 模块。也可从每个提示词步骤直接进入对应配置。

全局配置修改后，已生成提示词保持不变；需重跑提示词步骤及后续步骤。

准备素材目录

视频与图片按同名自动成组，生成数量来自实际素材，无需填写次数或整理中间 CSV。

例如 a001.mp4 配 a001.png。_1 / _2 始终是补充参考图，不是首尾帧。缺少必需图片或重名冲突时会停下并列出问题。

准备好目录，点击下方“一键生成”即可自动匹配并开始。

CSV 素材表

CSV 非空字段优先，空白字段继承统一参数。支持引号内逗号、换行和 UTF-8 BOM；其中的文件路径须可被服务器读取。

尚未导入素材表。

共用素材与参数（可选）：未匹配到专属图片时可使用这里的共用图片；不同素材仍各自生成一条视频。

单文件最大 1 GB。
留空时，请在下方描述新首图和运动需求。
