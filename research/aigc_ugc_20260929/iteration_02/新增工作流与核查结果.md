## R19 · MikeBot 语音参考（API 图）

[本地文件](reference_workflows/Lewis-Stuart-11/f5_tts.json) · [固定版本来源](https://github.com/Lewis-Stuart-11/MikeBot/blob/182b1d1a3d7bcb7746c14ab3d0d357623481bef8/workflows/audio/f5_tts.json)

**建议：历史参考，暂不直接接生产。**

链路：LoadAudio → F5TTSAudioInputs → SaveAudio；Textbox 分别提供参考音频转录和目标台词。

准备：参考音频必须由你提供，参考转录必须逐字匹配。交付文件已改为 reference_voice.wav 和中性示例文案，不包含原作者身份音频。节点包来源及与当前 F5 模型的兼容性尚需在安装前确认；不同权重的许可也应单独核对。

核查发现：这是 class_type/inputs 形式的 API JSON，没有 UI 节点坐标。不能按常规画布图的导入方式保证恢复；先在 ComfyUI 里重建短链，再核对其 /object_info 与实际 API 字段。音频投递是工作台接入的前置条件。

根图节点数：5。子图节点类型已递归登记在 manifest；未做所有连线语义验证。

交付修改：参考转录和目标台词改为中性原创示例，音频路径改为自备素材占位，输出前缀改为 research/voice。实际参考转录仍需与你自己的音频完全一致。

## R20 · MikeBot 旧口型参考（API 图）

[本地文件](reference_workflows/Lewis-Stuart-11/latentsync_with_frame_interpolation.json) · [固定版本来源](https://github.com/Lewis-Stuart-11/MikeBot/blob/182b1d1a3d7bcb7746c14ab3d0d357623481bef8/workflows/video/latentsync_with_frame_interpolation.json)

**建议：历史参考；优先采用第一轮当前 wrapper 图。**

链路：VHS_LoadVideo ＋ LoadAudio → D_VideoLengthAdjuster → D_LatentSyncNode → VHS_VideoCombine。

准备：原作者示例仍引用 Mike_Test.mp4 与 MichaelPoundVoice4.mp3；这些媒体未提供，应改为自备视频和音频。图中加载、长度调节和导出均为 25fps；默认 pingpong 会为较长音频往返重复帧。

核查发现：当前 ShmuelRonen wrapper 注册 LatentSyncNode / VideoLengthAdjuster，没有这些 D_ 名称。不能只改类名就假设输入字段兼容。文件名含 interpolation，但静态图没有独立 FILM/RIFE 插帧节点。第一轮的 UI 示例也要核对所选 checkpoint，文件名 1.5 不等于实际运行版本。

根图节点数：5。子图节点类型已递归登记在 manifest；未做所有连线语义验证。

## R21 · 两片段接缝（UI 图）

[本地文件](reference_workflows/stuttlepress/Lightweight%20VACE%20Clip%20Joiner%20v1.0.4.json) · [固定版本来源](https://github.com/stuttlepress/ComfyUI-Wan-VACE-Video-Joiner/blob/ae7445578e209ed54234c5f4caba57d2012e413a/Lightweight%20VACE%20Clip%20Joiner%20v1.0.4.json)

**建议：第二批，先于 full 验证。**

链路：两路 LoadVideo → GetVideoComponents → WanVACEPrep → WanVaceToVideo → 采样／解码 → 视频保存。

准备：原作者的 ComfyUI-Wan-VACE-Prep 是核心附加节点；地址为 https://github.com/stuttlepress/ComfyUI-Wan-VACE-Prep 。当前快照默认使用 Wan2.2 Fun VACE 高低噪 14B 与匹配 LoRA，轻量指图结构，不能推导显存低。

核查发现：两路视频要分别投递，统一尺寸／帧率并保留必要上下文。先避免可选编译或非本机支持的加速路径。要改 Wan2.1 VACE 时，应按作者说明替换完整采样配置，不能把普通 T2V 权重当 VACE 使用。

根图节点数：32。子图节点类型已递归登记在 manifest；未做所有连线语义验证。
