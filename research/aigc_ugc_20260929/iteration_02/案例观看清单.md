## 一次看片只填这张卡

```text
案例 ID / 标题：
来源 URL：
实际观看日期：
片段时间码（观看后填写）：
能看到原始输入吗：有 / 无 / 仅部分
真实资产：人物 / 商品 / 动作 / 声音 / 相机 / 场景
生成资产：
保留的是原像素、表演，还是身份参考：
成功点（仅写画面确实呈现的）：
失败或可疑点（没有观察到则留空）：
作者说法与画面观察不一致之处：
是否公开 JSON / 模型 / 参数 / 素材：
是否有自己的硬件实测：
下一次本地实验只验证的问题：
```

影片能播放、作者公开了文件、文件能运行、输出符合本项目标准，是四个独立检查点。不要用一个检查点替代其他三个。
